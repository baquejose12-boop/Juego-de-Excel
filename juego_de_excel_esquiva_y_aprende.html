¿Cómo compartir este juego con tus amigos/alumnos?

Este juego es un archivo web único e independiente (HTML). Para compartirlo mediante un enlace directo:

  1. GitHub Pages (Gratis y Recomendado): Sube este archivo con nombre index.html a un repositorio público de GitHub y activa GitHub Pages en los ajustes. Obtendrás un link como https://tu-usuario.github.io/juego-excel.
  2. Netlify / Vercel: Arrastra la carpeta que contiene este archivo en Netlify Drop para obtener un enlace público instantáneo en menos de 10 segundos.
  3. Google Drive: Sube el archivo y utiliza un convertidor de alojamiento directo como drv.tw para generar una URL ejecutable.
